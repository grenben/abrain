# Private Codex source modules

## Experimental private Codex source

- `src/core/ai/providers/codex-proposal.ts` — ephemeral structured proposal adapter; native schema/image files, validated lifecycle, typed failures and conservative scratch cleanup. `codex-input.ts` snapshots/validates input before admission, `codex-schema.ts` rejects unsupported schemas and validates results, `codex-images.ts` and `codex-image-containers.ts` validate full containers, `codex-image-decode.ts` verifies JPEG/WebP pixels; `codex-png.ts` checks PNG chunks, bounded inflation and decoded pixels before admission, `codex-lifecycle.ts` separates transport events from application JSON, `codex-process.ts` settles POSIX process groups, `codex-contract.ts` owns limits/failure types, and `codex-runtime.ts` owns fixed argv and host instructions. `codex-qualification.ts` has no qualified production runtime; fake-executable hashes are registered only by tests.
- `src/core/ai/private-policy.ts` — trusted file-only private opt-in and strict explicit-pin checks without discovery. `private-roles.ts` is an incomplete dispatch inventory. `private-route-audit.ts` reports uninspected planes and incomplete feature acceptance; CLI `private-codex audit --json` opens no database or provider.
- `src/core/ai/codex-dispatch.ts` — durable subscription admission and observed proposal dispatch. `subscription-context.ts` carries host-owned async scopes; `subscription-admission.ts` reserves/settles account lanes and attempt/turn/repair limits; `subscription-schema.ts` is installed by registered migration v223 on both engines. Unresolved attempts retain ownership. `codex-chat.ts` adapts bounded chat/expansion/OCR through this path. `recipes/codex-cli.ts` declares subscription/schema capability without claiming native tools or inventing prices.
- `src/core/ai/chat-format.ts` — deterministic OpenAI prompt-cache key derivation extracted from the gateway; its existing gateway export is preserved.
- `src/core/config-path.ts` — engine-free config path helpers, re-exported by `config.ts`; retains the `GBRAIN_HOME/.gbrain` convention.
- `src/core/cycle/extract-atoms-model.ts` — atom extraction's special model resolver, with strict private routing and the legacy fail-soft behavior outside private mode; re-exported from `extract-atoms.ts`.
- `src/core/cycle/triage-client.ts` — gateway judge adapter extracted from synthesize, preserving its exports and legacy provider behavior. `triage-codex.ts` supplies Codex's native bounded schema, complete-quote/entity grounding, route checks and a distinct cache version. `codex-chat.ts` calls a trusted `responseSchema.validateCodexProposal` callback before accepting the turn. Private triage is sequential; schema/lifecycle/semantic failures never become cached judgments. `test/ai/codex-triage.serial.test.ts` exercises the real pass, gateway, executable and PGLite cache with no network.
- `src/core/minions/handlers/subagent-result-mode.ts` — result mode/fallback token stamping extracted from the legacy handler. Private mode selects the explicit host read protocol before legacy client construction; legacy native-loop jobs remain refused.

- `src/core/minions/subscription-jobs.ts` — trusted queue subscription grants, immutable versioned job/authority/model/source-incarnation binding, per-call worker fencing and cancellation. `subscription-job-schema.ts` supplies migration v224 and the bootstrap claim fence; older workers cannot claim subscription jobs. `subscription-child.ts` tracks child readiness and blocks older child binaries. `queue-model-admission.ts` preserves the legacy native-tool capability check extracted from the queue.

- `src/commands/jobs/subscription.ts` — explicit CLI call/turn/deadline limits, separate auxiliary USD consent and no-write preview; help lives in `jobs/help.ts`. `ai/private-schedules.ts` validates file-only recurring allowances; `minions/subscription-schedules.ts` binds automatic cycle grants to an absolute slot deadline. `subscription-job-kinds.ts` separates deterministic freshness from possible generation. `cycle/subscription-budget.ts` keeps cycle subscription admission separate from USD estimates, with null totals and gateway enforcement.

- `src/core/facts/codex-proposals.ts` supplies bounded fact/classification schemas and host quote/identity checks. `cycle/extract-atoms-codex.ts` validates whole atom proposals and host admission; `extract-atoms-grounding.ts` owns the shared quote locator. `cycle/grade-takes-codex.ts` validates evidence and serializes private ensembles. `ai/codex-synopsis.ts` validates chunk-grounded synopses; its pure version constant lives in `codex-versions.ts`.
- `src/core/extract/rollup-cost.ts` separates unknown subscription totals from known API subtotals for extraction diagnostics. Migration v225 adds the rollup subscription counter. `test/helpers/codex-facts-contract.ts` runs production features and accounting with fake executables on PGLite and PostgreSQL.

- `src/core/cycle/patterns-codex.ts` — bounded private pattern dispatcher and native schema/semantic checks, selected before the legacy probe/agentic path. `codex-publication-plan.ts` retains immutable source/authority/evidence-bound plans (migration v226), reuses prepared-write request identities and advances watermarks only after receipts. `codex-publication-prepare.ts` validates locked evidence and adds transactional provenance through the existing page preparer. `subscription-jobs.ts` supplies a transaction-scoped job-claim fence; `persistence/journal.ts` preserves it across admission retries. `test/helpers/codex-publication-contract.ts` shares the production-path fixtures across engines. Bounded synthesis integration is described below.

- `src/core/cycle/synthesize-codex.ts` — strict private synthesis dispatcher, pending-plan recovery, completion and cooldown. `synthesize-codex-input.ts` snapshots source-scoped transcripts; `synthesize-codex-proposal.ts` owns native chunk schemas, grounding and host-generated note identities. `synthesize-codex-admission.ts` reserves configured daily chunk allowances atomically in the existing config store, including failed calls and recent legacy submissions. `codex-publication-files.ts` bounds file reads and validates retained file identity/hash. `synthesize-summary-slug.ts` holds the unchanged summary namespace helper, re-exported by the synthesis façade. `test/helpers/codex-synthesis-contract.ts` shares full transcript-to-pattern, recovery and budget fixtures across engines.

See [private Codex status and acceptance gaps](../../development/private-codex-status.md).

- `src/core/minions/codex-upgrade-snapshot.ts` — bounded explicit job/dependency snapshots with sanitized drain/park dispositions. `codex-upgrade-park.ts` retains graph parking and rollback receipts; `codex-upgrade-schema.ts` supplies v249 database fences against old-worker claims and ordinary resume. `codex-upgrade-resubmit.ts` binds reviewed new payloads to existing queue/subscription admission in one transaction, preserving old parked identities. CLI `src/cli/private-codex/jobs.ts` exposes selected-job previews, parking, restoration and reviewed-file resubmission. Shared PGLite/PostgreSQL tests live in `test/helpers/codex-upgrade-jobs-contract.ts`; see [queued-job cutover](../../development/private-codex-job-upgrade.md).

- `src/core/ai/private-pin-plan.ts` — bounded generative pin inventory, sanitized previews and immutable plans. `private-pin-file.ts` journals native-lock-protected configuration replacement and recovery; other configuration writers must be stopped. `private-pin-database.ts` commits pins and receipts together under a table lock. `private-upgrade-schema.ts` supplies migration v248 on both engines. CLI `src/cli/private-codex/pins.ts` exposes explicit plane/hash-bound preview, apply, receipt and rollback commands, separate from activation; see the [pin checkpoint](../../development/private-codex-pins.md).

- `src/core/minions/handlers/subagent-codex.ts` — sequential ephemeral proposal loop for explicitly versioned read and write jobs. `codex-action-contract.ts` validates trusted job fields and generates one-action/final native schemas from the authorized registry. `codex-action-tools.ts` confines existing page reads to the bound source/prefixes and projects bounded public results. `codex-action-store.ts` reuses existing message/tool ledgers with claim-fenced transactions, database-returned canonical IDs, immutable inputs and result-first recovery. `test/helpers/codex-actions-contract.ts` exercises real queue/worker/read/history paths and injected crash seams on both engines. `codex-action-writes.ts` retains host admissions and reconciles prepared protocol-3 page-write receipts; `persistence/codex-action-{schema,guard,prepare}.ts` preserves untrusted page protections and adds worker/revision fencing. Remote delegation remains unsupported; see the [action checkpoint](../../development/private-codex-actions.md).

- `src/commands/think-subscription.ts` + `src/core/ai/subscription-auxiliary.ts` — local CLI subscription bounds and source-incarnation request identity, enclosing both generation and publication; durable independent embedding/reranking reservations preserve unknown-usage holds. Thin clients cannot grant these allowances. Shared contract: `test/helpers/codex-think-automation-contract.ts`; operator limits: `docs/development/private-codex-think-automation.md`.

- `src/core/ai/codex-eval-schema.ts` + registered `v257-codex-eval-results.ts` — shared host run/receipt tables with protocol, binding, lease and bounded JSONB payload checks. The schema generator includes these tables in both fresh engines; migration replay and catalog fixtures cover parity. No production migration is applied by development tests.

- `src/core/brainstorm/codex-judge.ts` — strict private branch of the actual `runJudge` entrypoint: sequential native schema chunks, exact ID coverage, host-computed rubric/LSD verdicts and versioned retained proposals. `private-roles.ts` inventories its distinct judge pin. Shared engine tests: `test/helpers/codex-brainstorm-judge-contract.ts`; scope and remaining whole-run work: [brainstorm checkpoint](../../development/private-codex-brainstorm.md).
