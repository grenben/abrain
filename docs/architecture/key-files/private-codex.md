# Private Codex source modules

## Experimental private Codex source

- `src/core/ai/providers/codex-proposal.ts` — ephemeral structured proposal adapter; native schema/image files, validated lifecycle, typed failures and conservative scratch cleanup. `codex-input.ts` snapshots/validates input before admission, `codex-schema.ts` rejects unsupported schemas and validates results, `codex-images.ts` and `codex-image-containers.ts` validate full containers, `codex-image-decode.ts` verifies JPEG/WebP pixels; `codex-png.ts` checks PNG chunks, bounded inflation and decoded pixels before admission, `codex-lifecycle.ts` separates transport events from application JSON, `codex-process.ts` settles POSIX process groups, `codex-contract.ts` owns limits/failure types, and `codex-runtime.ts` owns fixed argv and host instructions. `codex-qualification.ts` has no qualified production runtime; fake-executable hashes are registered only by tests.
- `src/core/ai/private-policy.ts` — trusted file-only private opt-in and strict explicit-pin checks without discovery. `private-roles.ts` is an incomplete dispatch inventory. `private-route-audit.ts` reports uninspected planes and incomplete feature acceptance; CLI `private-codex audit --json` opens no database or provider.
- `src/core/ai/codex-dispatch.ts` — durable subscription admission and observed proposal dispatch. `subscription-context.ts` carries host-owned async scopes; `subscription-admission.ts` reserves/settles account lanes and attempt/turn/repair limits; `subscription-schema.ts` is installed by registered migration v223 on both engines. Unresolved attempts retain ownership. `codex-chat.ts` adapts bounded chat/expansion/OCR through this path. `recipes/codex-cli.ts` declares subscription/schema capability without claiming native tools or inventing prices.
- `src/core/ai/chat-format.ts` — deterministic OpenAI prompt-cache key derivation extracted from the gateway; its existing gateway export is preserved.
- `src/core/config-path.ts` — engine-free config path helpers, re-exported by `config.ts`; retains the `GBRAIN_HOME/.gbrain` convention.
- `src/core/cycle/extract-atoms-model.ts` — atom extraction's special model resolver, with strict private routing and the legacy fail-soft behavior outside private mode; re-exported from `extract-atoms.ts`.
- `src/core/cycle/triage-client.ts` — gateway judge adapter extracted from synthesize, preserving its exports and legacy provider behavior. `triage-codex.ts` supplies Codex's native bounded schema, complete-quote/entity grounding, route checks and a distinct cache version. `codex-chat.ts` calls a trusted `responseSchema.validateCodexProposal` callback before accepting the turn. Private triage is sequential; schema/lifecycle/semantic failures never become cached judgments. `test/ai/codex-triage.serial.test.ts` exercises the real pass, gateway, executable and PGLite cache with no network.
- `src/core/minions/handlers/subagent-result-mode.ts` — result mode/fallback token stamping extracted from the legacy handler. Private mode refuses its native loop before client construction; the host action loop is not implemented yet.

- `src/core/minions/subscription-jobs.ts` — trusted queue subscription grants, immutable versioned job/authority/model/source-incarnation binding, per-call worker fencing and cancellation. `subscription-job-schema.ts` supplies migration v224 and the bootstrap claim fence; older workers cannot claim subscription jobs. `subscription-child.ts` tracks child readiness and blocks older child binaries. `queue-model-admission.ts` preserves the legacy native-tool capability check extracted from the queue.

- `src/commands/jobs/subscription.ts` — explicit CLI call/turn/deadline limits, separate auxiliary USD consent and no-write preview; help lives in `jobs/help.ts`. `ai/private-schedules.ts` validates file-only recurring allowances; `minions/subscription-schedules.ts` binds automatic cycle grants to an absolute slot deadline. `subscription-job-kinds.ts` separates deterministic freshness from possible generation. `cycle/subscription-budget.ts` keeps cycle subscription admission separate from USD estimates, with null totals and gateway enforcement.

- `src/core/facts/codex-proposals.ts` supplies bounded fact/classification schemas and host quote/identity checks. `cycle/extract-atoms-codex.ts` validates whole atom proposals and host admission; `extract-atoms-grounding.ts` owns the shared quote locator. `cycle/grade-takes-codex.ts` validates evidence and serializes private ensembles. `ai/codex-synopsis.ts` validates chunk-grounded synopses; its pure version constant lives in `codex-versions.ts`.
- `src/core/extract/rollup-cost.ts` separates unknown subscription totals from known API subtotals for extraction diagnostics. Migration v225 adds the rollup subscription counter. `test/helpers/codex-facts-contract.ts` runs production features and accounting with fake executables on PGLite and PostgreSQL.
