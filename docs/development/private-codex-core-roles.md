Development only. The extended-role branch through `57592ea142` is integrated.

at `66439961c3`. Native concept synthesis and fence repair are committed at `0bb41ab1b8`.

Concepts use the reasoning tier, source-scoped public atom evidence, exact
quotes and numeric grounding before accepting a turn. The existing concept
publication path preserves human-owned pages, canonical fences and provenance.
A changed input revision or policy refuses publication. API-priced budgets do
not meter subscription calls; cost remains unknown. Inference errors do not
publish fallback pages. Small concept groups keep deterministic synthesis.

Fence repair uses the deep tier and one bounded native proposal per candidate.
Table repairs and tail classifications must pass the existing preservation and
exposure gates before the turn is accepted. The runner retains explicit model
repair opt-in, source ownership, preview hashes, attempt claims and coordinated
file/database publication. A policy change invalidates the preview. Subscription
allowances stay separate from API USD caps; no API fallback or invented price.

Validation uses registered fake executables, synthetic source data and isolated
PGLite/PostgreSQL databases. It is not real-model acceptance or a full CI run.
Ordinary concept/fence regressions, role-policy revocation, exhausted admission,
canonical file publication and source revision races are included. Sanitized
run counts and hashes belong in the associated local handoff receipt.

Core workflows now bind the complete policy through cache reads and publication.
Triage verdicts, grading caches, take-proposal tombstones and enrichment completion
keys distinguish policy changes. Retained think plans carry their role and policy;
unpublished plans cannot be adopted after a tier or activation change. Existing
committed write receipts remain available for reconciliation. Legacy scalar
publication plans remain recoverable only under scalar policy. This does not
reset completed atom extraction or other committed content merely because a
model policy changes.

Known core queue producers check explicit role activation and tier pins before
inserting jobs. Explicit cycle phase selections check their corresponding roles;
implicit cycles retain feature-level gates so optional phases do not become
mandatory queue dependencies. Freshness-only cycles remain model-free. Native
loops, remote delegation and generative callers outside the registered bounded
role implementations retain their existing refusals. Queue inventory is not a
claim that every alternative GBrain feature is supported.
